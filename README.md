# CrossDrop

CrossDrop est une application de transfert de fichiers entre appareils grâce à une connexion pair-à-pair (P2P).

## Fonctionnement

1. Ouvrez CrossDrop sur les deux appareils.
2. Sur le premier appareil, créez une session.
3. Un code de session est généré.
4. Sur le deuxième appareil, saisissez ce code pour rejoindre la session.
5. Une fois les appareils connectés, sélectionnez les fichiers à envoyer.
6. Les fichiers sont transférés directement entre les deux appareils.

## Technologies

- Electron
- Node.js
- WebRTC
- Socket.IO
- Simple Peer

## Téléchargement

Les installateurs Windows et macOS sont disponibles dans les [Releases](https://github.com/vilian743/CrossDrop/releases).

## Lancer le projet

```bash
git clone https://github.com/vilian743/CrossDrop.git
cd CrossDrop
npm install
npm start
```
